定位

合规优先、可自托管、可插拔权威数据源的法律智能体平台。把引用核验、人工复核、数据分级、审计留痕做成 Agent 工作流的强制必经节点，而不是生成后补个脚注。

代码仓库（含完整后端、React 工作台、MCP Server、51+ 单测与 CI）：github.com/Ai-Kaffey/lexguard-agent

明确不做
自建法规全文库、通用问答机器人、C 端法律意见、诉讼结果预测、电子签、声称零幻觉、无标注集就发布准确率。
合规映射
AI 仅辅助工具、公众内容标识、关键环节强制人工复核留痕、日志留存 ≥3 年、敏感数据不出域、引用回权威库全文比对、AI 使用声明。
演示数据纪律
法条只存编号 + 效力 + 主旨摘要；案号统一 DEMO-CASE；企业 DEMO- 前缀。主打防幻觉的项目自带伪造案号即自毁。
本页边界
纯前端模拟，便于快速体验交互与 UI；真实运行请 clone 仓库执行 npm run dev，可接任意 OpenAI 兼容接口与权威数据源。
